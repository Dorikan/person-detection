
# 🚀 PairDETR Video Inference

Инструмент для высокопроизводительного запуска кастомной модели PairDETR (на базе архитектуры Deformable DETR) на видеопотоке. Проект включает в себя полный пайплайн: от загрузки специфичных весов и кастомной архитектуры голов до эстетичной визуализации результатов.

## ✨ Особенности

-   Поддержка PairDETR: Полная реализация кастомной логики forward pass и декодирования выходов (8 координат для пар Subject-Object).
    
-    Эстетичная визуализация:
    

-   Ультра-тонкие рамки (1px) для минимального визуального шума.
    
-   Адаптивные полупрозрачные подложки под текст (эффект "матового стекла") для лучшей читаемости.
    

-    Оптимизация: Поддержка GPU (CUDA), работа с тензорами PyTorch.
    
-   CLI Интерфейс: Удобный запуск через консоль с гибкой настройкой параметров.
    

## 📦 Установка

### 1. Перед запуском надо установить зависимости
```
pip install -r requirements.txt
```
### 2. Загрузка модели
Модель можно загрузить из git lfs или с [HuggingFace](https://huggingface.co/MTSAIR/PairDETR/resolve/main/pytorch_model.bin).

## 🚀 Использование

Точка входа в программу — файл `main.py`.
### Пример использования:
```
python main.py \
    --source inputs/walking.mp4 \
    --weights weights/pairdetr_best.pth \
    --output results/walking_processed.mp4 \
    --conf 0.4 \
    --device cpu
```

### Аргументы командной строки

|**Аргумент**|**Тип**|**Default**|**Описание**|
|--|--|--|--|
|`--source`    |`str`  | **Required**| Путь к входному видеофайлу.|
|`--weights`   |`str`  | `pytorch_model.pth` |Путь к весам модели (`.pth`).|
|`--conf`      |`float`| `0.25` |Порог уверенности (Confidence Threshold). Отсекает слабые детекции.|
|`--output`    |`str`  | `auto` |Путь для сохранения результата. Если не указан, создается автоматически.|
|`--target-fps`|`int`  | `None` |FPS выходного видео. Если не указан, сохраняется оригинальный FPS.|
|`--device`    |`str`  | `cuda`/`cpu` |Устройство для вычислений.|

## 🛠 Технические детали

### Архитектура PairDETR

Модель имеет модифицированные головы предсказания, которые выдают **8 координат** на один запрос (Subject-Object pairs), что отличается от стандартных 4-х координат.

### Визуализация

Для отрисовки используется **OpenCV** с кастомной функцией `draw_styled_box`, которая использует алгоритм наложения (`cv2.addWeighted`) для создания полупрозрачного фона под текстом, обеспечивая чистый и читаемый вывод.
